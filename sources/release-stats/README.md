# AI usage in JupyterLab pull requests

Computed on 2026-10-05 with [`tools/ai_usage.py`](../../tools/ai_usage.py) from the pull request descriptions (re-run: `python3 tools/ai_usage.py 4.6.0`, with a JupyterLab checkout in `~/jupyterlab` and an authenticated `gh`).

## Method

- PR list: the cumulative `## 4.6.0` entry of the JupyterLab `CHANGELOG.md` (376 PRs: 7 new features, 61 enhancements, 97 bug fixes, 144 maintenance, 27 other, 38 documentation, 2 deprecations). The 4.7.0a0, a1 and a2 entries give the PRs merged after 4.6.0.
- Each PR body fetched with `gh api graphql` (cached locally in `raw-<version>.json`, not committed). One row per PR, with the answer, is in `prs-<version>.json`.
- The PR template asks since 2026-02-13 ([jupyterlab/jupyterlab#18413](https://github.com/jupyterlab/jupyterlab/pull/18413)): "- **YES or NO**: Some or all of the content of this PR was generated by AI." The script reads that bullet. Free-text answers under an "AI usage" heading count too: "None", "N/A", "No AI" and "I'm a human" are no; five descriptive answers were read by hand (`OVERRIDES` in the script).
- PRs by bots (43 in 4.6) are left out. PRs without the section (most were opened before the question existed) and two left blank are not in the denominator.
