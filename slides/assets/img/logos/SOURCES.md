# Logo sources

All files were downloaded unchanged (byte for byte) on 2026-10-05. None of them was recoloured, redrawn or edited. `preview.png` shows every file on white and on `#0a0f1d` navy.

Padding: `jupyter-foundation.svg` and `quansight.svg` are cropped to the artwork. The other files have transparent padding inside their viewBox: the logo fills 68% of the height in the three OpenTeams files and 72% in `quansight-white.svg`. At the same image height, these files show a smaller logo.

## Jupyter Foundation

- `jupyter-foundation.svg`: colour logo ("jupyter" in grey, "foundation" in orange), for light backgrounds.
  - Source: https://jupyterfoundation.org/wp-content/uploads/sites/16/2024/11/jupyter_fnd_color.svg (the header logo of jupyterfoundation.org, on a white header).
  - Fetched: 2026-10-05.
  - The same bytes (blob `5e5835fbf0f81a75eea469eac00d76aefa7cd27c`) are in the Linux Foundation landscape repository `jmertic/lf-landscape`, path `hosted_logos/jupyter_foundation.svg`, commit `6162a450438905f2e41ddfc1a2514f908c478031`.
- No dark-background file was found. The site's social image https://jupyterfoundation.org/wp-content/uploads/sites/16/2024/11/jupyter_fnd_soc2.png shows a reversed version (white "jupyter" and moons), but only inside a 1200 x 628 photo. `doc/media/images/foundation-dark.svg` in `jupyter-governance/jupyter-foundation-governing-board` is a different lockup that reads "jupyter foundation board".
- Guidelines: the jupyterfoundation.org footer says "Jupyter® is a registered trademark of LF Charities, Inc., and trademark usage guidelines applicable to the Jupyter name and logo can be found at https://lf-charities.org/trademark-policy/".

## Quansight (Quansight PBC)

- `quansight.svg`: colour logo (mark and wordmark), for light backgrounds.
  - Source: https://quansight.com/wp-content/uploads/2024/05/Quansight-logo-cropped.svg (quansight.com WordPress media item 8484, alt text "Image of the Quansight logo").
  - Fetched: 2026-10-05.
  - The same bytes (blob `9b2ea4e82acb960df452d656dac370a0c960fa2c`) are in the website repository `Quansight/Quansight-website`, commit `578fd5404f6d3a7c022db43d54077bd522ee17b3`, path `apps/consulting/public/posts/delivering-open-source-expertise-to-the-enterprise-with-our-quansight-labs-partnership/Quansight-logo-cropped.svg`.
- `quansight-white.svg`: all-white logo, for dark backgrounds (official). It is the footer logo of quansight.com, on the `#452393` purple footer.
  - Source: https://quansight.com/wp-content/uploads/2023/08/PyTorch_page-logo-06.svg (media item 2811). The file name is the site's own. The artwork is the full Quansight logo, with the same shapes as `quansight.svg`.
  - Fetched: 2026-10-05.
  - The quansight.com header shows the same white logo as a raster file, https://quansight.com/wp-content/uploads/2023/06/quansight-logo-no-tagline.webp (1076 x 520).
- Guidelines: no brand guideline, press kit or logo licence was found on quansight.com. The footer reads "@2018-2026 Quansight PBC All rights reserved."
